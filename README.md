# myers-gh1328/tap

Homebrew formulas for myers-gh1328 projects.

```bash
brew install myers-gh1328/tap/guarded-update
```

| Formula | Project |
| --- | --- |
| `guarded-update` | [myers-gh1328/guarded-update](https://github.com/myers-gh1328/guarded-update) |

A workflow (`.github/workflows/update.yml`) moves each formula to its
project's newest release every six hours; run it by hand from the
Actions tab to pick up a release sooner.
